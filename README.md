# Simple Messaging App

Simple Messaging App merupakan aplikasi pesan sederhana berbasis web yang dikembangkan menggunakan PHP Native dan teknologi web lainnya.

## Teknologi
- HTML
- CSS
- JavaScript Native
- PHP Native 8.4
- MariaDB

## Deskripsi
Proyek ini dibuat sebagai bagian dari tugas praktikum dengan menerapkan pemisahan frontend dan backend serta komunikasi menggunakan API.
